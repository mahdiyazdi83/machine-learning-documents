## How to read the documents

Each session is a **single self-contained HTML file**. Download the file and open it in a modern browser; no internet connection or extra installation is required.

The documents are designed to be read in layers:

1. **Start with the learning map** to understand the shape of the session.
2. **Follow the main sections in order** when studying the topic for the first time.
3. **Use diagrams and flows** to build a visual mental model before focusing on details.
4. **Open expandable sections** when you need longer examples, implementation details, or additional context.
5. **Read notes and warnings carefully**; they highlight common misunderstandings and important boundaries.
6. **Use the quizzes and review prompts** to check your understanding without rereading the entire document.

## What you will find inside

The exact content changes from one session to another, but the reading experience stays consistent:

## Recommended study path

If you are following the course, begin with Session 01 and continue in order. If you are revisiting a specific subject, use the session table above and the built-in search at the top of each document.

Session 04 also includes a **topic-first reference**. Read the regular session document first, then use the reference as a faster decision and revision guide.

۱. چرا اصلاً به ML نیاز پیدا کردیم؟

برای چند خانه، چند تصویر یا چند مشتری می‌توان با بررسی دستی تصمیم گرفت. اما وقتی تعداد نمونه‌ها بسیار زیاد، سرعت تولید داده بالا و شکل داده متنوع می‌شود، قواعد دستی هم پرهزینه می‌شوند و هم استثناهای فراوان پیدا می‌کنند. تشخیص چهره نمونهٔ خوبی است: نوشتن فهرستی از قواعد ثابت برای تمام زاویه‌ها، نورها، سن‌ها و پوشش‌ها عملاً شکننده است؛ داده می‌تواند این تنوع را بهتر نمایش دهد.

Volume

مقدار داده آن‌قدر زیاد است که پردازش دستی مقیاس‌پذیر نیست.

Velocity

داده با سرعت بالا تولید می‌شود و تصمیم باید به‌موقع باشد.

Variety

عدد، متن، تصویر، صدا و ساختارهای متفاوت کنار هم‌اند.

Veracity

کیفیت، خطا، سوگیری و قابل‌اعتمادبودن داده مسئله‌اند.

Value

هدف انبارکردن داده نیست؛ باید ارزش قابل‌استفاده از آن استخراج شود.

ML زمانی انتخاب خوبی است که الگو وجود دارد، مثال کافی داریم و تعریف عملکرد روشن است. اگر قانون مسئله ساده، قطعی و پایدار باشد، یک برنامهٔ معمولی می‌تواند ارزان‌تر، شفاف‌تر و قابل‌اعتمادتر باشد.

۴. خانواده‌های اصلی یادگیری را با نوع بازخورد تشخیص بده

Supervised

برای هر Sample جواب یا Label داریم. مدل نگاشت X به y را یاد می‌گیرد.

Unsupervised

فقط X را داریم و دنبال ساختار، شباهت یا گروه‌های پنهان می‌گردیم.

Reinforcement

Agent در Environment عمل می‌کند و از Reward/Penalty رفتار بهتر می‌آموزد.

یادگیری تقویتی به‌صورت حلقه
Agent← ActionEnvironment← State + RewardAgent
در مثال جاروبرقی رباتیک، تمیزکردن پاداش و برخورد با دیوار تنبیه است؛ رفتار از تعامل‌های تکراری شکل می‌گیرد.

Semi-supervised حالت میانی است: چند نمونه Label دارند و تعداد زیادی بی‌برچسب‌اند. اطلاعات محدود برچسب‌دار به استفادهٔ بهتر از ساختار دادهٔ بی‌برچسب کمک می‌کند. تفاوت خانواده‌ها در «الگوریتم مشهور» نیست؛ در نوع اطلاعات و بازخورد موجود است.

۵. در Supervised Learning: Regression یا Classification؟

برای تشخیص، به شکل y نگاه کن. اگر جواب روی یک محور پیوسته قرار می‌گیرد—مثل قیمت، دما یا زمان—مسئله Regression است. اگر جواب یکی از دسته‌های مشخص است—مثل قبول/رد یا گربه/سگ—مسئله Classification است. عددبودن Label لزوماً Regression نمی‌سازد؛ صفر و یک ممکن است فقط نام دو Class باشند.

پرسش: مقدار چقدر است؟ خروجی پیوسته؛ مثال: قیمت خانه.

پرسش: این نمونه متعلق به کدام Class است؟ Label مرجع داریم.

پرسش: چه گروه‌هایی در داده دیده می‌شوند؟ Label مرجع در آموزش وجود ندارد.

Notebook دوم تفاوت Classification و Clustering را با ۱۵۰ نقطه و چهار رنگ نشان می‌دهد. وقتی رنگ‌های y را حذف می‌کنیم، فقط هندسهٔ نقاط باقی می‌ماند. الگوریتم خوشه‌بندی باید از نزدیکی ساختار بسازد؛ اما نزدیک‌بودن هندسی همیشه دقیقاً همان معنای واقعی گروه نیست.

۶. زبان مشترک داده: Sample، Feature، X و y

مدل با داستان خام مسئله کار نمی‌کند؛ با ماتریس‌ها کار می‌کند. معمولاً X یک جدول دوبعدی است: هر سطر یک Sample و هر ستون یک Feature. y پاسخ متناظر هر سطر است. تعداد سطرهای X و y باید برابر باشد.

در تصویر، یک Sample می‌تواند یک عکس و Featureها مقدار پیکسل‌ها یا ویژگی‌های استخراج‌شده باشند. انتخاب اینکه چه چیزی Sample و چه چیزی Feature باشد یک تصمیم مهندسی است و مستقیماً روی چیزی که مدل قادر به یادگیری است اثر می‌گذارد.

۷. چرخهٔ کامل؛ از دادهٔ خام تا استفادهٔ واقعی

جمع‌آوری←پاک‌سازی←Feature / Label←Train←Evaluate←Inference

در Training، مدل Prediction می‌سازد، خطا سنجیده می‌شود و Parameterها تغییر می‌کنند. این حلقه بارها تکرار می‌شود. در Inference، Parameterها ثابت‌اند و مدل برای ورودی تازه پاسخ می‌سازد. پس Training و استفادهٔ روزمره دو حالت متفاوت‌اند.

Evaluation فقط مرحلهٔ آخر نیست. اگر Metric نامناسب، دادهٔ آلوده یا Test لو‌رفته باشد، حلقه می‌تواند با اطمینان به جهت اشتباه حرکت کند. در محصول واقعی چرخه ادامه دارد: دادهٔ جدید، افت کیفیت، تغییر رفتار کاربران و نیاز به بازآموزی باید پایش شوند.

۱۰. از Prediction تا Error، Loss و Cost

برای هر خانه، اختلاف Prediction و مقدار واقعی یک Error است. جمع سادهٔ Errorهای علامت‌دار مناسب نیست، چون خطای مثبت و منفی همدیگر را خنثی می‌کنند. قدرمطلق یا مربع خطا این مشکل را رفع می‌کند. Loss معمولاً خطای یک Sample و Cost خلاصهٔ Lossها روی مجموعه است، هرچند در منابع مختلف این دو واژه گاهی جابه‌جا استفاده می‌شوند.

Absolute Error

|ŷ − y|

هم‌واحد با Target و تعبیرش ساده است.

Squared Error

(ŷ − y)²

خطاهای بزرگ را شدیدتر جریمه می‌کند و به Outlier حساس‌تر است.

error = y_pred - y
cost = np.sum(np.abs(error))
print(cost)

Cost فقط وقتی مفید است که دقیقاً بدانیم روی چه داده و با چه واحدی محاسبه شده. جمع خطا با زیادشدن تعداد نمونه بزرگ‌تر می‌شود؛ میانگین برای مقایسهٔ دیتاست‌های هم‌مقیاس خواناتر است.

۱۱. مدل چطور بهتر می‌شود؟ از Grid Search تا Optimizer

در مثال آموزشی، مقدارهای مختلف a و b روی یک شبکه امتحان می‌شوند. برای هر زوج، Prediction و Cost ساخته می‌شود و کم‌هزینه‌ترین زوج انتخاب می‌شود. مزیت این روش شفافیت است: می‌توانیم ببینیم یادگیری در اصل جست‌وجوی Parameterهایی است که معیار خطا را بهتر می‌کنند.

costs, params = [], []
for a in np.arange(-1, 1, 0.1):
    for b in np.arange(-50, 51, 1):
        y_pred = a * X + b
        cost = np.sum(np.abs(y_pred - y))
        costs.append(cost)
        params.append((a, b))

best_a, best_b = params[np.argmin(costs)]

با دو Parameter این روش قابل‌فهم است؛ با هزاران Parameter تعداد ترکیب‌ها انفجاری می‌شود. ضبط سوم نشان می‌دهد می‌توان Parameterها را مرحله‌به‌مرحله اصلاح کرد تا Cost پایین بیاید. هر اصلاح یک Iteration است و Solver/Optimizer جهت Update را تعیین می‌کند. Gradient Descent در این جلسه معرفی می‌شود و آموزش جزئی‌ترش به جلسهٔ دوم می‌رسد.

حلقهٔ بهینه‌سازی
Parameter فعلی←Prediction←Cost←Update↺
هدف صفرکردن خطا به هر قیمت نیست؛ هدف ساختن مدلی است که روی دادهٔ ندیده نیز خوب عمل کند.

۱۳. محدودیت‌ها و دام‌های واقعی جلسه

۱۴. خودآزمایی؛ نقشهٔ ذهنی را محک بزن

فرق برنامه‌نویسی مستقیم با ML چیست؟

در برنامه‌نویسی مستقیم، انسان قانون را صریح می‌نویسد؛ در ML، الگوریتم Parameterهای یک رابطه را از مثال‌ها پیدا می‌کند. هر دو به کدنویسی و طراحی دقیق نیاز دارند.

از کجا بفهمیم مسئله Regression است یا Classification؟

به معنای Target نگاه می‌کنیم: مقدار پیوسته مانند قیمت → Regression؛ دستهٔ گسسته مانند سگ/گربه → Classification.

فرق Unsupervised و Reinforcement Learning چیست؟

Unsupervised در دادهٔ بی‌برچسب دنبال ساختار می‌گردد؛ Reinforcement Agent را با عمل در Environment و Reward/Penalty آموزش می‌دهد.

چرا جمع سادهٔ Errorهای علامت‌دار مناسب نیست؟

خطاهای مثبت و منفی می‌توانند همدیگر را خنثی کنند. قدرمطلق یا مربع مانع پنهان‌شدن خطا می‌شود.

Parameter و Hyperparameter چه فرقی دارند؟

Parameter از داده یاد گرفته می‌شود، مثل a و b؛ Hyperparameter چگونگی آموزش را کنترل می‌کند، مثل گام Grid یا max_iter.

چرا خروجی خوب روی Train کافی نیست؟

ممکن است Model مثال‌های دیده‌شده و Noise آن‌ها را حفظ کرده باشد. تعمیم فقط روی دادهٔ ندیده سنجیده می‌شود.

واژه‌نامهٔ سریع جلسهٔ اول

اصطلاحمعنای کاربردی
Sampleیک نمونه یا سطر از داده؛ مثل یک خانه یا تصویر.
Featureاطلاعات ورودی که Sample را توصیف می‌کند.
Target / Labelجواب مرجع در Supervised Learning.
Modelرابطهٔ یادگرفته‌شده برای تبدیل ورودی به Prediction.
Trainingمرحله‌ای که Parameterها از داده اصلاح می‌شوند.
Inferenceاستفاده از Model ثابت برای ورودی تازه.
Loss / Costعدد بیانگر بدی Prediction برای یک Sample یا مجموعه.
Optimizerروش Updateکردن Parameterها برای کاهش Cost.
Iterationیک مرحلهٔ اصلاح Parameterها.
Generalizationعملکرد خوب روی داده‌ای که Model در آموزش ندیده است.
جمع‌بندی: جلسهٔ اول یک زنجیره می‌سازد: مسئله را صورت‌بندی کن، Sample و Feature و Target را تعریف کن، Model را آموزش بده، خطایش را درست بسنج و نتیجه را فقط با تعمیم به دادهٔ تازه معتبر بدان.

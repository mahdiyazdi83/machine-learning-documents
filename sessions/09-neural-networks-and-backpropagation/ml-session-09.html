۲. نورون مصنوعی؛ یک تابع کوچک و یادگرفتنی

الهام زیستی به یک محاسبه ساده می‌شود: ورودی‌های x، وزن‌های w، مقدار b و تابع g.

z = x₁w₁ + x₂w₂ + … + xₙwₙ + b = XW + b
a = g(z)
Weight

شدت و جهت اثر هر Feature را یاد می‌گیرد.

Bias

آستانه را جابه‌جا می‌کند تا مرز تصمیم مجبور نباشد از مبدأ بگذرد.

Activation

رفتار خروجی و Nonlinearity را تعیین می‌کند.

نکتهٔ کلیدی: چند لایهٔ خطی بدون Activation غیرخطی در نهایت فقط یک تبدیل خطی‌اند.

۳. Activation Functionها

g(z)=z برای خروجی Regression مناسب است، ولی در Hidden Layer Nonlinearity اضافه نمی‌کند.
σ(z)=1/(1+e⁻ᶻ) خروجی را بین صفر و یک می‌برد؛ در نواحی اشباع Gradient کوچک می‌شود.
ReLU(z)=max(0,z) ساده و سریع است؛ برای z منفی Gradient صفر است.
import numpy as np

def linear(x):
    return x

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def relu(x):
    return np.maximum(0, x)

def softmax(logits):
    stable = logits - logits.max(axis=1, keepdims=True)
    exp = np.exp(stable)
    return exp / exp.sum(axis=1, keepdims=True)
پایداری عددی: کم‌کردن بزرگ‌ترین Logit احتمال Overflow در exp را کم می‌کند، بدون اینکه Probability نهایی تغییر کند.

۵. Forward Pass و Loss

def forward(self, X):
    self.z1 = X @ self.params["W1"] + self.params["b1"]
    self.a1 = relu(self.z1)
    self.z2 = self.a1 @ self.params["W2"] + self.params["b2"]
    self.a2 = softmax(self.z2)
    return self.a2
MSE برای Regression
MSE = (1/m) Σ(y − ŷ)²
Cross-Entropy برای Classification
L = −(1/m) Σ log p(yᵢ|xᵢ)
def cross_entropy(y_pred, y_true):
    n = y_true.shape[0]
    selected = y_pred[np.arange(n), y_true]
    return np.mean(-np.log(selected + 1e-9))

۶. Backpropagation؛ خطا چگونه عقب می‌رود؟

Forward مقادیر میانی را نگه می‌دارد. Backward از مشتق Loss نسبت به Logit خروجی شروع می‌کند و با Chain Rule به وزن‌های قبل می‌رسد.

dZ₂ = Ŷ − Y
dW₂ = A₁ᵀdZ₂/m + λW₂
dZ₁ = (dZ₂W₂ᵀ) ⊙ ReLU′(Z₁)
dW₁ = XᵀdZ₁/m + λW₁
def backward(self, X, y):
    m = X.shape[0]
    one_hot = np.zeros_like(self.a2)
    one_hot[np.arange(m), y] = 1
    dz2 = self.a2 - one_hot
    dW2 = self.a1.T @ dz2 / m + self.reg_lambda * self.params["W2"]
    db2 = dz2.sum(axis=0, keepdims=True) / m
    dz1 = dz2 @ self.params["W2"].T * relu_derivative(self.z1)
    dW1 = X.T @ dz1 / m + self.reg_lambda * self.params["W1"]
    db1 = dz1.sum(axis=0, keepdims=True) / m
    return {"W1": dW1, "b1": db1, "W2": dW2, "b2": db2}
Gradient خود Update نیست: Optimizer با Learning Rate و حافظهٔ Gradientهای قبلی تصمیم می‌گیرد Parameter چقدر جابه‌جا شود.

۸. Digits و یک MLP قابل‌اجرا

load_digits دارای ۱٬۷۹۷ تصویر ۸×۸ است؛ هر تصویر به ۶۴ Feature و Target به یکی از ده Class تبدیل می‌شود.

from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neural_network import MLPClassifier

X, y = load_digits(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42
)
model = make_pipeline(
    StandardScaler(),
    MLPClassifier(hidden_layer_sizes=(64, 32), activation="relu",
                  solver="adam", max_iter=300, random_state=42,
                  early_stopping=True, validation_fraction=0.1)
)
model.fit(X_train, y_train)
print(model.score(X_test, y_test))
warm_start=True و max_iter=1: برای نمایش EpochبهEpoch شدنی است، اما Validation باید ثابت و Variableها درست باشند؛ برای آموزش عادی یک Fit استاندارد شفاف‌تر است.

۹. Keras: Sequential، Compile و Fit

from tensorflow import keras
from tensorflow.keras import layers

model = keras.Sequential([
    layers.Input(shape=(64,)),
    layers.Dense(64, activation="relu"),
    layers.Dense(32, activation="relu"),
    layers.Dense(10, activation="softmax"),
])
model.compile(optimizer="adam",
              loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
stop = keras.callbacks.EarlyStopping(
    monitor="val_loss", patience=10, restore_best_weights=True
)
history = model.fit(X_train, y_train, validation_split=0.1,
                    epochs=100, batch_size=32, callbacks=[stop])
test_loss, test_accuracy = model.evaluate(X_test, y_test)
Sequential

۲. Ensemble یعنی یک تصمیم، چند دیدگاه

به‌جای اینکه نتیجه را به یک Model بسپاریم، چند Learner می‌سازیم و Output آن‌ها را ترکیب می‌کنیم. فایده زمانی ظاهر می‌شود که اعضا دقیقاً یک خطا را تکرار نکنند؛ یعنی در Sample، Feature، Algorithm یا Hyperparameterها تنوع داشته باشند.

سه معماری اصلی جلسه
Bagging
X → [M1 ‖ M2 ‖ M3] → vote / mean

اعضا موازی‌اند و جواب‌ها تجمیع می‌شوند.

Boosting
X → M1 → error → M2 → error → M3

اعضا ترتیبی‌اند و عضو بعدی روی ضعف قبلی کار می‌کند.

Stacking
[M1(X), M2(X), M3(X)] → Meta Model

Prediction اعضا Featureهای سطح دوم می‌شوند.

تنوع Dataset/Feature و تجمیع ساده؛ مناسب برای کم‌کردن وابستگی به یک Learner ناپایدار.
تمرکز ترتیبی روی خطا؛ هر مرحله به نتیجهٔ مرحلهٔ قبل وابسته است.
ترکیب یادگرفتنی با Meta-model؛ کیفیت دادهٔ سطح دوم تعیین‌کننده است.

۳. Bagging: اعضا موازی، داده‌ها کمی متفاوت

هر عضو روی یک زیرمجموعه یا Bootstrap Sample از داده آموزش می‌بیند. در Classification، رأی اکثریت یا Probabilityهای میانگین‌شده جواب نهایی را می‌سازند؛ در Regression معمولاً میانگین Predictionها استفاده می‌شود.

classification: ŷ = mode(ŷ₁, ŷ₂, …, ŷ_B)   |   regression: ŷ = (1/B) Σᵦ ŷᵦ
Sample متفاوت

هر Learner نسخه‌ای کمی متفاوت از Train می‌بیند.

آموزش موازی

عضوها برای Fit به Prediction یکدیگر وابسته نیستند.

تجمیع

Vote، Mean یا Weighted Mean خروجی نهایی را می‌سازد.

تنوع واقعی لازم است: اگر همهٔ Modelها داده و تنظیمات یکسان ببینند و خطاهای یکسان بسازند، زیادشدن تعداد اعضا به‌تنهایی معجزه نمی‌کند.

۴. Random Forest یک Bagging تخصصی از Decision Treeهاست

Random Forest چند Decision Tree می‌سازد. علاوه بر تفاوت Sampleها، در هر Split فقط بخشی از Featureها Candidate هستند؛ بنابراین Treeها کمتر شبیه هم می‌شوند. پارامترهایی مثل n_estimators، criterion، max_depth، max_features و min_samples_split رفتار Forest را کنترل می‌کنند.

from sklearn.ensemble import RandomForestClassifier
from sklearn.tree import plot_tree
model = RandomForestClassifier(n_estimators=100, criterion="entropy")

model.fit(X_train, y_train)
score = model.score(X_test, y_test)

tree_0 = model.estimators_[0]
plot_tree(tree_0, max_depth=3, filled=True)
plt.savefig("tree-00.png", dpi=180, bbox_inches="tight")
ترتیب مهم است: در Notebook، دسترسی به model.estimators_ قبل از fit نوشته شده است. Forest کامل با plot_tree رسم نمی‌شود؛ باید یکی از Estimatorهای Fitشده را انتخاب کرد.

۵. BaggingClassifier وقتی Base Learner را خودمان انتخاب می‌کنیم

from sklearn.ensemble import BaggingClassifier
from sklearn.svm import SVC

clf = BaggingClassifier(
    estimator=SVC(kernel="rbf", probability=True),
    n_estimators=100,
    random_state=42,
)
clf.fit(X_train, y_train)
prediction = clf.predict(X_test)

در Bagging استاندارد، Estimator پایه Clone می‌شود؛ بنابراین همهٔ اعضا از یک خانواده‌اند اما Sampleهای متفاوت می‌بینند. اگر قرار است Algorithmهای واقعاً متفاوت را ترکیب کنیم، Voting یا Stacking ساختار طبیعی‌تری است.

Classifier یا Regressor؟ نوع همهٔ اجزا باید با مسئله هماهنگ باشد. برای Classification از Classifier و برای پیش‌بینی مقدار پیوسته از Regressor و تجمیع عددی استفاده می‌کنیم.

۶. Boosting: عضو بعدی برای اصلاح قبلی می‌آید

برخلاف Bagging، آموزش ترتیبی است. Learner اول بخشی از Pattern را می‌گیرد؛ سپس اطلاعات خطا به مرحلهٔ بعد می‌رسد تا روی Sampleها یا Residualهای سخت‌تر تمرکز کند. مدل نهایی ترکیب وزن‌دار Learnerهای ضعیف است.

Weak Learner 1←خطاهای مهم←Weak Learner 2←اصلاح باقی‌مانده
Weak یعنی محدود، نه بی‌فایده: مثلاً یک Decision Stump فقط یک Split دارد و مسئله را کامل حل نمی‌کند، اما چند Stump با وزن مناسب می‌توانند مرز قوی‌تری بسازند.

۷. Sample Weight پیام خطا را به مرحلهٔ بعد منتقل می‌کند

class_weight به یک Class کامل اهمیت بیشتری می‌دهد؛ sample_weight می‌تواند اهمیت هر ردیف را جدا تعیین کند. مثال Notebook وزن همهٔ Sampleها را ۱ می‌گذارد، وزن Predictionهای غلط را یک واحد زیاد می‌کند و بعد کل بردار را Normalize می‌کند.

sample_weights = np.ones_like(y_true, dtype=float)
sample_weights[y_true != y_pred] += 1

sample_weights /= sample_weights.sum()
model2.fit(X, y, sample_weight=sample_weights)
wᵢ ← wᵢ × exp(α · I[yᵢ ≠ h(xᵢ)])   سپس   wᵢ ← wᵢ / Σⱼwⱼ

در Array ده‌عضوی Notebook چهار Prediction غلط وجود دارد؛ بعد از Normalize، وزن نمونهٔ درست 1/14 و وزن نمونهٔ غلط 2/14 می‌شود. این یک نمایش شهودی است؛ AdaBoost واقعی وزن Learner و شدت خطا را هم در Update دخالت می‌دهد.

۸. AdaBoost چند Classifier ضعیف را به Strong Classifier تبدیل می‌کند

هر Round یک Weak Learner را با وزن‌های فعلی Fit می‌کند. Sampleهای غلط در Round بعد مهم‌تر می‌شوند و Learnerهای دقیق‌تر سهم بیشتری در Vote نهایی می‌گیرند.

from sklearn.ensemble import AdaBoostClassifier
from sklearn.tree import DecisionTreeClassifier

clf = AdaBoostClassifier(
    estimator=DecisionTreeClassifier(max_depth=1),
    n_estimators=100,
    learning_rate=0.1,
    random_state=42,
)
clf.fit(X_train, y_train)
تفاوت با Notebook: Source کلاس DecisionTreeClassifier() کامل را گذاشته است. برای نمایش کلاسیک Weak Learner، max_depth=1 روشن‌تر است؛ Tree عمیق ممکن است روی Train بیش از حد قوی شود.

۹. Haar-like Feature به‌جای Pixel خام، اختلاف ناحیه‌ها را می‌سنجد

در Case Study تشخیص چهره، Rectangleهای روشن و تیره روی Window حرکت می‌کنند. Feature مقدار مجموع Pixelهای یک ناحیه را از ناحیهٔ مجاور کم می‌کند؛ مثلاً ناحیهٔ چشم معمولاً از گونه تیره‌تر است. دو‌مستطیلی، سه‌مستطیلی و چهار‌مستطیلی شکل‌های اصلی مقاله‌اند.

Edge Feature

اختلاف دو Rectangle مجاور؛ مناسب برای مرز روشن/تیره.

Line Feature

ناحیهٔ میانی با دو طرف مقایسه می‌شود.

Diagonal Feature

اختلاف زوج‌های قطری در چهار Rectangle.

عدد مهم مقاله: برای Window پایهٔ 24×24 حدود ۱۶۰٬۰۰۰ Rectangle Feature ممکن وجود دارد. هیچ Feature به‌تنهایی «چهره» نیست؛ AdaBoost تعداد کمی Feature مؤثر را انتخاب و ترکیب می‌کند.

۱۰. Integral Image مجموع هر Rectangle را با چهار مراجعه می‌دهد

هر خانهٔ Integral Image مجموع تمام Pixelهای بالا و چپ خودش، با احتساب همان خانه، است. هزینهٔ ساخت این جدول یک بار پرداخت می‌شود؛ بعد مجموع یک Rectangle بزرگ دیگر به تعداد Pixelهایش وابسته نیست.

II(x,y) = Σ₍x′≤x,y′≤y₎ I(x′,y′)
sum(D) = II(x₂,y₂) + II(x₁−1,y₁−1) − II(x₁−1,y₂) − II(x₂,y₁−1)
import cv2, numpy as np

img = np.arange(1, 31, dtype=np.uint8).reshape(5, 6)
ii = cv2.integral(img)
print(ii.shape)  # (6, 7): یک ردیف و ستون صفر اضافه می‌شود
print(ii[-1, -1])  # 465، مجموع کل تصویر
پل به Real-time: Haar Featureها باید در Locationها و Scaleهای بسیار زیاد محاسبه شوند. Integral Image محاسبهٔ مجموع Rectangle را ثابت و سریع می‌کند؛ همین سرعت، Cascade را عملی می‌سازد.

۱۱. Viola–Jones: Feature سریع + انتخاب AdaBoost + Cascade

Window تصویر←Haar Features←AdaBoost Selection←Cascade Stages

Stage اول با چند Feature ارزان بیشتر Windowهای غیرچهره را رد می‌کند. فقط Candidateهای امیدوارکننده وارد Stageهای بعدی و گران‌تر می‌شوند. در مقاله، Cascade نهایی ۳۸ Stage دارد؛ هدف معماری این است که Average Cost پایین بماند، نه اینکه همهٔ Windowها تمام Featureها را طی کنند.

Positive

نمونه‌های چهرهٔ روبه‌رو و تقریباً هم‌تراز.

Negative

Windowهای فاقد چهره؛ False Positiveهای سخت می‌توانند دوباره وارد Train شوند.

XML نهایی

Featureها، Thresholdها و Stageهای آموزش‌دیده برای Detection ذخیره می‌شوند.

پارامتر Detectionبرداشت عملی
scaleFactorفاصلهٔ Scaleهای متوالی در Scan؛ کوچک‌تر یعنی Scan ریزتر و معمولاً کندتر.
minNeighborsحداقل همسایه‌های لازم برای نگه‌داشتن Detection؛ افزایش آن Detectionهای ضعیف را سخت‌گیرانه‌تر حذف می‌کند.
minSizeObjectهای کوچک‌تر از این اندازه بررسی نمی‌شوند.
محدودیت Domain: Detector مقاله برای چهرهٔ روبه‌رو Train شده است. Rotation زیاد، زاویهٔ نزدیک Profile، نور پشت شدید یا پوشاندن چشم‌ها می‌تواند Detection را خراب کند. CNNها و Transformerها جایگزین‌های جدیدتری‌اند، اما Cascade هنوز برای مسئله‌های سبک و محدود کاربرد دارد.

۱۲. Stacking به یک Meta-model یاد می‌دهد به کدام عضو اعتماد کند

چند Base Model متفاوت Prediction می‌دهند. این Predictionها کنار هم Matrix سطح دوم را می‌سازند و Final Estimator روی آن Fit می‌شود. برخلاف Vote ساده، Meta-model می‌تواند یاد بگیرد در چه Patternهایی کدام Base Model مفیدتر است.

from sklearn.ensemble import StackingClassifier
from sklearn.linear_model import LogisticRegression

estimators = [
    ("tree", DecisionTreeClassifier(max_depth=5)),
    ("svc", SVC(probability=True)),
    ("knn", KNeighborsClassifier()),
]

stack = StackingClassifier(
    estimators=estimators,
    final_estimator=LogisticRegression(),
    cv=5,
)
stack.fit(X_train, y_train)
prediction = stack.predict(X_test)
Leakage سطح دوم: اگر Meta-model را با Prediction همان داده‌ای Train کنیم که Base Model قبلاً روی آن Fit شده، نتیجه بیش از حد خوش‌بینانه می‌شود. StackingClassifier برای ساخت Featureهای Train از Cross-validated Prediction استفاده می‌کند.

۱۳. Gradient Boosting هر Tree را برای اصلاح Residual می‌سازد

در مثال شهودی Regression، Model اول Prediction می‌دهد. فاصلهٔ مقدار واقعی و Prediction به‌صورت Residual یا جهت منفی Gradient Loss محاسبه می‌شود؛ Tree بعدی برای تقریب همین Correction آموزش می‌بیند. عضو جدید از صفر مسئله را حل نمی‌کند، بلکه به مجموع قبلی اضافه می‌شود.

Fₘ(x) = Fₘ₋₁(x) + η · hₘ(x)
n_estimators

تعداد Stageهای اصلاح.

learning_rate

اندازهٔ سهم هر Tree در Update.

Tree Complexity

عمق و Leafها ظرفیت هر اصلاح را تعیین می‌کنند.

from sklearn.ensemble import GradientBoostingRegressor

model = GradientBoostingRegressor(
    n_estimators=100,
    learning_rate=0.05,
    max_depth=3,
    random_state=42,

model.fit(X_train, y_train)
Tree با Gradient Split نمی‌سازد: Tree همچنان یک Decision Tree عادی است؛ Gradient یا Residual تعیین می‌کند Target مرحلهٔ بعد چه Correctionی باشد.

۱۴. XGBoost، CatBoost و LightGBM یک اسم برای یک چیز نیستند

جلسه این Libraryها را به‌عنوان پیاده‌سازی‌های جدی خانوادهٔ Gradient Boosting معرفی کرد. همه Learnerهای ترتیبی می‌سازند، اما در رشد Tree، Regularization، پشتیبانی از Featureهای Categorical، دادهٔ Sparse و بهینه‌سازی CPU/GPU تفاوت دارند.

۱۵. تمرین جلسه: جهت کندل بعدی Bitcoin

Dataset ذخیره‌شده ۹۸۴ روز از 2024-01-01 تا 2026-09-10 دارد. هدف تمرین Regression قیمت نیست؛ یک Binary Classification است: آیا کندل روز بعد مثبت است یا منفی؟ Featureهای امروز به Label فردا وصل می‌شوند.

import pandas as pd
from xgboost import XGBClassifier
from sklearn.metrics import classification_report

df = pd.read_csv("BTC.csv", parse_dates=["Date"]).sort_values("Date")
df["direction"] = (df["Close"] - df["Open"] > 0).astype(int)
df["target_next_day"] = df["direction"].shift(-1)

features = ["Open", "High", "Low", "Close", "Volume"]
data = df.dropna(subset=["target_next_day"]).copy()
X = data[features]
y = data["target_next_day"].astype(int)

cut = int(len(data) * 0.8)
X_train, X_test = X.iloc[:cut], X.iloc[cut:]
y_train, y_test = y.iloc[:cut], y.iloc[cut:]

model = XGBClassifier(objective="binary:logistic", eval_metric="logloss")
model.fit(X_train, y_train)
print(classification_report(y_test, model.predict(X_test)))
هدف پایه

Close - Open > 0 برای روز بعد؛ ۱ یعنی کندل مثبت و ۰ یعنی منفی.

۱۸. مرور و خودآزمایی

فرق ساختاری Bagging و Boosting چیست؟

Bagging اعضا را مستقل و موازی روی Sampleهای متفاوت Fit می‌کند؛ Boosting ترتیبی است و هر Stage به خطای Stageهای قبل واکنش نشان می‌دهد.

چرا Random Forest از یک Decision Tree پایدارتر است؟

چند Tree با Sampleها و Featureهای متفاوت می‌سازد و خروجی را تجمیع می‌کند؛ بنابراین تصمیم به یک Split خاص وابسته نمی‌ماند.

فرق class_weight و sample_weight چیست؟

اولی وزن یک Class را تغییر می‌دهد؛ دومی می‌تواند برای هر ردیف وزن جدا داشته باشد.

Integral Image چرا مهم است؟

بعد از یک پیش‌محاسبه، مجموع هر Rectangle با چهار مراجعه به جدول به‌دست می‌آید و اندازهٔ Rectangle هزینه را تغییر نمی‌دهد.

چرا Cascade سریع است؟

Stageهای ارزان بیشتر Windowهای منفی را زود رد می‌کنند و فقط Candidateهای اندک وارد مراحل گران‌تر می‌شوند.

Stacking چه چیزی را یاد می‌گیرد؟

Meta-model یاد می‌گیرد Predictionهای Base Modelها را چگونه ترکیب کند؛ Featureهای سطح دوم باید بدون Leakage ساخته شوند.

Gradient Boosting Tree بعدی را برای چه Targetی می‌سازد؟

برای تقریب Residual یا جهت منفی Gradient Loss فعلی، تا مجموع Modelها Error باقی‌مانده را اصلاح کند.

در تمرین BTC چرا Split تصادفی خطرناک است؟

چون رکوردهای آینده ممکن است وارد Train شوند و Evaluation جهت کندل بعدی غیرواقعی خوش‌بینانه شود.
